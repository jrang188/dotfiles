# Directory Structure

## Top-Level Layout

```
dotfiles/
├── nix/                    # All Nix system configuration (primary content)
│   ├── flake.nix           # Flake entry point — inputs, outputs, helpers
│   ├── flake.lock          # Locked input versions
│   ├── Makefile            # Build shortcuts (darwin, nixos, clean, update, lint, format)
│   ├── home/               # Home Manager modules
│   ├── hosts/              # Host-specific system configs
│   ├── modules/            # Reusable system-level modules
│   ├── lib/                # Helper functions (Nix)
│   ├── pkgs/               # Custom package derivations
│   ├── scripts/            # Utility scripts
│   └── docs/               # Documentation
│
├── opencode/               # OpenCode AI tool config (symlinked ~/opencode)
│   ├── opencode.json       # OpenCode settings
│   ├── agents/             # GSD agent definitions (.md)
│   ├── skills/             # Custom skills
│   ├── command/            # GSD command definitions
│   ├── hooks/              # Session/tool hooks (JS/bash)
│   ├── get-shit-done/      # GSD runtime (bin, workflows, templates)
│   ├── plugins/            # OpenCode plugin data
│   └── package.json        # Node.js CJS marker
│
├── claude/                 # Claude Code config (to be symlinked ~/.claude)
│   ├── settings.json       # Claude Code settings (hooks, plugins, statusline)
│   └── .gsd-profile        # GSD user profile
│
├── nvim/                   # Neovim (LazyVim) config
│   ├── lua/                # Lua plugin configs
│   └── stylua.toml         # Lua formatter config
│
├── sketchybar/             # macOS status bar config
├── aerospace/              # macOS tiling WM config
├── wallpapers/             # Desktop wallpaper images
│
├── .planning/              # GSD project planning
│   └── codebase/           # Codebase map documents
│
├── CLAUDE.md               # Claude Code agent instructions
├── AGENTS.md               # OpenCode agent instructions
├── .stowrc                 # Stow config (--target=~/.config)
└── README.md               # Minimal readme
```

## nix/ Subdirectory Detail

### `nix/home/` — User environment (Home Manager)

```

├── default.nix             # Root imports + home.{username,homeDirectory,stateVersion}, nh
├── zsh.nix                 # Zsh + oh-my-zsh configuration
├── neovim.nix              # Neovim setup
├── git.nix                 # Git configuration + identity
├── oh-my-posh.nix          # Shell prompt theme
├── packages.nix            # Shared packages + direnv
├── ai/
│   ├── default.nix         # Imports claude-code.nix + mcp.nix
│   ├── claude-code.nix     # programs.claude-code (llm-agents.nix)
│   └── mcp.nix             # programs.mcp MCP server definitions
├── darwin/
│   ├── default.nix         # Imports gui.nix, packages.nix; adds macos oh-my-zsh plugin
│   ├── gui.nix             # macOS GUI app config
│   └── packages.nix        # Darwin-specific packages
├── nixos/
│   ├── kirby/
│   │   ├── default.nix     # kirby home imports
│   │   ├── hyprland.nix    # Hyprland WM + hyprlock + hypridle + hyprpaper + hyprsunset
│   │   ├── kde.nix         # KDE Plasma home config
│   │   ├── apps.nix        # kirby-specific applications
│   │   ├── rofi.nix        # App launcher
│   │   ├── swaync.nix      # Notification daemon
│   │   ├── ashell.nix      # Status bar
│   │   ├── theme.nix       # GTK/QT theming
│   │   ├── packages.nix    # kirby-specific packages
│   │   └── zen-browser.nix # Zen browser config
│   └── wsl/
│       └── default.nix     # WSL home config (orphaned — no flake output)
└── ubuntu/
    └── default.nix         # Ubuntu home config (orphaned — no flake output)
```

### `nix/hosts/` — Host system configurations

```
hosts/
├── darwin/
│   └── Sterling-MBP/
│       ├── default.nix     # hostname, users, dock persistent-apps
│       └── homebrew.nix    # Declarative Homebrew (brews + casks)
└── nixos/
    ├── kirby/
    │   ├── default.nix     # root imports, hostname, users, timezone, locale, system.stateVersion
    │   ├── boot.nix        # bootloader
    │   ├── secure-boot.nix # lanzaboote configuration
    │   ├── networking.nix  # network, DNSCrypt
    │   ├── desktop.nix     # display manager, desktop session
    │   ├── hardware.nix    # hardware-specific settings
    │   ├── hardware-configuration.nix  # auto-generated by nixos-generate-config
    │   ├── openrgb.nix     # RGB lighting
    │   ├── howdy.nix       # Facial recognition login
    │   └── packages.nix    # kirby system-level packages
    └── wsl/
        └── default.nix     # NixOS WSL config (orphaned — no flake output)
```

### `nix/modules/` — Reusable modules

```
modules/
├── common/
│   ├── default.nix         # Imports nix-core.nix, apps.nix
│   ├── nix-core.nix        # Nix settings, caches, fonts, allowUnfree/Broken, zsh
│   └── apps.nix            # Common system apps
├── darwin/
│   ├── default.nix         # Imports system.nix, security.nix
│   ├── system.nix          # macOS defaults, dock, activation scripts
│   └── security.nix        # macOS security settings
├── home/
│   ├── default.nix         # home module root
│   └── gui.nix             # GUI home-manager modules
└── nixos/
    ├── default.nix         # Imports all nixos modules, nix gc/optimise settings
    ├── flatpak.nix         # Flatpak support
    ├── nix-ld.nix          # Foreign binary support
    ├── 1password.nix       # 1Password system integration
    ├── hyprland.nix        # Hyprland system-level config
    ├── podman.nix          # Podman container runtime
    └── localsend.nix       # LocalSend firewall rules
```

## Naming Conventions

| Convention | Example |
|---|---|
| Files | `kebab-case.nix` — `claude-code.nix`, `nix-core.nix` |
| Directories | `kebab-case/` — `home-manager/`, `nixos/` |
| Host names | Proper case as-is — `Sterling-MBP`, `kirby` |
| Nix attributes | `camelCase` within expressions — `mkSystem`, `mkDarwin`, `mkSpecialArgs` |
| Module entry | `default.nix` in each directory |

## Key File Locations

| What | Where |
|---|---|
| Flake definition | `nix/flake.nix` |
| All flake inputs | `nix/flake.nix:4-47` |
| Shared packages | `nix/home/packages.nix` |
| MCP server config | `nix/home/ai/mcp.nix` |
| Homebrew packages | `nix/hosts/darwin/Sterling-MBP/homebrew.nix` |
| kirby Hyprland | `nix/home/nixos/kirby/hyprland.nix` |
| Nix cache keys | `nix/modules/common/nix-core.nix` |
| Build commands | `nix/Makefile` |
| Claude Code config | `claude/settings.json` |
| GSD profile | `claude/.gsd-profile` + `opencode/.gsd-profile` |
