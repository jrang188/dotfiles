# opencode/

## Responsibility

Agent configuration for OpenCode (v2, the npm `@opencode/cli` line) — the AI coding assistant used in this repository. Defines the agent model, plugin pipeline, MCP server registry (tool access), sub-agent presets with per-role model assignments, and skill definitions consumed by the agent runtime.

## Design

**Multi-file configuration tree:**

- `opencode.json` — **Generated by Nix** (`nix/home/ai/opencode.nix` via `programs.opencode.settings`, written at build time to `~/.config/opencode/opencode.json`). Gitignored — do not edit by hand. Carries model, plugin list, and agent sub-type toggles using native v2 keys.
- `cli.json` — **Generated by Nix** (`xdg.configFile."opencode/cli.json"`, written at build time to `~/.config/opencode/cli.json`). Global v2 terminal config; sets the `tokyonight` theme (`theme.name`). Replaces v1's layered `tui.json`, which v2 removed.
- `oh-my-opencode-slim.json` — Multi-preset plugin config ("oh-my-opencode-slim"). Defines orchestration roles (orchestrator, oracle, librarian, explorer, designer, fixer, observer) with model, variant, skill, and MCP assignments. Two presets: `openai` and `opencode-go` (active).
- `.oh-my-opencode-slim/` — Plugin bookkeeping (tracked): `skills-manifest.json` records each installed skill's package version, source/last-seen hash, and status (`managed` vs `customized`); `skill-updates/<version>/` stages upstream skill bundles pending review.
- `settings.json` — Empty placeholder (no user overrides)
- `.gitignore` — Excludes runtime artifacts installed by tools (`agents/`, `command/`, `get-shit-done/`, `hooks/`, `plugins/`, `gsd-*` state), Nix-managed configs (`opencode.json`, `cli.json`), and runtime/deps (`node_modules/`, `package.json`, `package-lock.json`, `bun.lock`)
- **No lockfile or install tree lives in this directory** — opencode v2 installs and loads plugins under `~/.cache/opencode/npm/<pkg>@latest/<timestamp>/node_modules/…` (log: `entrypoint=file:///…/oh-my-opencode-slim@latest/1791879293444/node_modules/oh-my-opencode-slim/dist/server/index.js`), where `toml` resolves to 4.3.0. The v1 install-tree artifacts that used to sit here (`node_modules/`, `package-lock.json`, `bun.lock`) were deleted/untracked in `056c3cd`; the lockfile was the repo's only tracked npm manifest, so Dependabot's two `toml` advisories (GHSA-v5mp-jgw5-2x6j, GHSA-82x6q7mm-w9cf) closed with it. Only the `{"type":"commonjs"}` stub `package.json` was deliberately kept.
- `plugins/petdex.js` — **Stale v1 artifact** (petdex-generated, gitignored via `plugins/`): exports a v1-style function default, but v2 requires a default object with an `id` plus an `effect`/`setup`, so it fails to load every session (`WARN … PluginModule.LoadError: Plugin must export a default definition with an id and an effect or setup function`).

**Agent configuration (`opencode.json` — Nix-managed):**

| Key | Value | Notes |
|---|---|---|
| `model` | `opencode-go/deepseek-v4.1-flash` | Default model for the agent |
| `plugins` | `["oh-my-opencode-slim"]` | v2 key (v1: `plugin`). The GitHub-hosted `superpowers` plugin is no longer loaded |
| `agents.explore.disabled` | `true` | Explore sub-agent turned off (v1: `agent.explore.disable`) |
| `agents.general.disabled` | `true` | General sub-agent turned off (v1: `agent.general.disable`) |
| `experimental.subagent_depth` | `2` | Raises v2's default subagent-nesting cap of 1 so advisor subagents can read images |

v1's `lsp = true` was dropped — v2 accepts the key but runs no language servers, exposes no LSP tools, and emits no diagnostics.

The above settings live in `nix/home/ai/opencode.nix`, not the (generated) JSON file. **MCP server registry is NOT in `opencode.json` directly** — it is defined once in `nix/home/ai/mcp.nix` (`programs.mcp.servers`) and merged into `programs.opencode.settings.mcp` via `enableMcpIntegration` (the flat v1 `mcp` shape is still normalized in memory by v2).

**MCP server registry** (single source: `nix/home/ai/mcp.nix`, consumed by both Claude Code and OpenCode):

| Server | Type | Endpoint |
|---|---|---|
| `nixos` | `local` | `uvx mcp-nixos` |
| `astro` | `remote` | `https://mcp.docs.astro.build/mcp` |
| `kubernetes` | `local` | `npx -y kubernetes-mcp-server@latest` |
| `opentofu` | `streamable-http` | `https://mcp.opentofu.org/mcp` |
| `grafana` | `local` | `op run -- uvx mcp-grafana` against `grafana.tail8255cc.ts.net` |

**Preset plugin (`oh-my-opencode-slim.json`):**

Two presets, each defining sub-agent roles (`opencode-go` is active via the top-level `preset` key):

| Role | `openai` preset model | `opencode-go` preset model | Skills | MCPs |
|---|---|---|---|---|
| orchestrator | `openai/gpt-5.5` | `opencode-go/glm-5.3-flash` (high) | `*` (openai) | all except context7 (openai) |
| oracle | `openai/gpt-5.5` (high) | `opencode-go/kimi-k3` (max) | `simplify` (openai) | none |
| librarian | `openai/gpt-5.4-mini` (low) | `opencode-go/deepseek-v4.1-flash` (high) | none | websearch, context7, grep_app (openai); websearch, context7, gh_grep (opencode-go) |
| explorer | `openai/gpt-5.4-mini` (low) | `opencode-go/deepseek-v4.1-flash` (high) | none | none |
| designer | `openai/gpt-5.4-mini` (medium) | `opencode-go/mimo-v2.6-flash` | `agent-browser` (openai) | none |
| fixer | `openai/gpt-5.4-mini` (low) | `opencode-go/deepseek-v4.1-flash` (high) | none | none |
| observer | — | `opencode-go/mimo-v2.5` | none | none |

The `council` role is gone; `observer` exists only in the `opencode-go` preset. Roles without an explicit `skills` / `mcps` entry inherit the plugin defaults.

**Multiplexer (tmux) integration** (`multiplexer` key): `type: auto` detects a terminal multiplexer (tmux/zellij/herdr/cmux/kitty) and opens a pane per background agent so sub-agent work is visible live. `layout: main-vertical` keeps the main session at `main_pane_size: 60` with agents stacked in the side pane. The v1 workaround that injected an explicit `--port` (via an `opencode()` wrapper in `nix/home/zsh.nix`) is **currently commented out** in that file — the function is retained only as reference.

**Skills directory** (`skills/`): Contains three custom skill packages, each with a `SKILL.md`, `README.md`, and `codemap.md`:

| Skill | Purpose (from SKILL.md) |
|---|---|
| `clonedeps/` | Cloning dependency repositories |
| `codemap/` | Building and maintaining codemap documentation files (includes `scripts/` subdirectory) |
| `simplify/` | Simplifying / refactoring code |

The remaining `skills/` entries (`deepwork/`, `loop-engineering/`, `oh-my-opencode-slim/`, `reflect/`, `release-smoke-test/`, `verification-planning/`, `worktrees/`) ship as plugin-managed `SKILL.md` files.

## Flow

1. **Agent launch**: OpenCode (the `opencode2` binary aliased to `opencode`) reads `opencode.json`, selects the model, loads the `oh-my-opencode-slim` plugin, reads terminal settings from `cli.json`, and initializes the MCP servers.
2. **Preset selection**: `oh-my-opencode-slim.json` provides a preset (active: `opencode-go`). The orchestrator role dispatches tasks to sub-agents (oracle, librarian, explorer, designer, fixer, observer) each with a distinct model, variant/effort, skill set, and MCP access.
3. **MCP tool invocation**: When the agent needs domain-specific data (NixOS package info, Astro docs, Kubernetes cluster state, OpenTofu infrastructure, Grafana metrics), it routes the request to the appropriate MCP server.
4. **Skill execution**: Sub-agents load skills from the `skills/` directory or from the `oh-my-opencode-slim` plugin. The `simplify` skill is specifically assigned to the oracle role.

## Integration

| Consumer / Dependency | Mechanism | Details |
|---|---|---|
| **OpenCode runtime** | `opencode.json` + `cli.json` (generated) | Primary config consumed by the OpenCode CLI; determines model, plugins, MCPs, and terminal theme. Both written to `~/.config/opencode/` by Home Manager |
| **Home Manager (`nix/home/ai/opencode.nix`)** | `programs.opencode.settings` + `xdg.configFile."opencode/cli.json"` | Source of truth for both generated files; also pins the package to `inputs.llm-agents.packages.${system}.opencode2` (v2) wrapped in a `symlinkJoin` that adds the `opencode` bin alias |
| **Home Manager (`nix/home/ai/mcp.nix`)** | `programs.mcp.servers` | Single source of truth for the MCP registry; merged into `opencode.json` via `enableMcpIntegration` |
| **oh-my-opencode-slim plugin** | `plugins` key | JSON config loaded as a plugin; defines sub-agent role topology and model routing |
| **MCP servers (external)** | `mcp` key in `opencode.json` | NixOS (local uvx), Astro (remote), Kubernetes (local npx), OpenTofu (remote), Grafana (local via 1Password) — defined in `nix/home/ai/mcp.nix` |
| **Stow / dotfiles** | `.gitignore` | Runtime artifacts and `opencode.json` / `cli.json` (Nix-managed) excluded from version control. No npm lockfile is tracked — v1's was untracked in `056c3cd`; v2 keeps its plugin install tree in `~/.cache/opencode` |
